A make.fun entry for the **Two-Sentence Horror** competition: the scariest
horror story you can tell in exactly two sentences.

## The story

> My phone keeps changing my sister's name to remains whenever I type it.
> I opened the custom dictionary to delete the entry and found it was added
> the day she was born, by an account that has not logged in since.

211 characters, two sentences. The first sentence is a small everyday
annoyance; the second reveals the entry was waiting since the day she was
born — and whoever put it there never came back.

## How it works

`main.py` (Python 3.13, standard library only) writes the fixed story to
`/output/entry.txt`. It is fully deterministic: every run writes the exact
same bytes.

```bash
python3 main.py
```
